# 🦖 foodZILLA - The Beast of Healthy Recipes
> **منصة وصفات الطعام الصحي والطلب الإلكتروني بطابع سينمائي حماسي**  
> *A Cinematic & Gamified Healthy Food Platform Built for Youth & Young Adults.*

---

## 🌟 About The Project (عن المشروع)
**foodZILLA** هو مشروع ويب تفاعلي يهدف إلى كسر الصورة النمطية بأن "الطعام الصحي ممل أو صعب الطبخ". صُمم الموقع بطابع حماسي مستوحى من وحش "جودزيلا" لجذب المراهقين والشباب، وتزويدهم بوصفات صحية غنية بالعناصر الغذائية (بروتين، كاربوهيدرات، فواكه، ألبان، وحلويات صحية)، مع حساب دقيق للسعرات الحرارية، وفيديوهات شرح من يوتيوب، ونظام سلة تسوق إلكتروني متكامل.

---

## 🚀 Key Features (أهم المميزات)

1. **🦖 Cinematic Godzilla Header:** تصميم فريد بخلفية نارية متحركة وشعاع ذري ووميض برق باستخدام CSS3 Keyframes الخالصة.
2. **🥗 Nutrition Categories:** تصنيف ذكي للوجبات حسب نوع الفائدة الغذائية (Protein, Carbohydrates, Sweets, Fruits, Dairy).
3. **🔍 Instant Dual-Search:** بحث فوري ذكي يبحث باسم الوصفة أو بأي مكون من مكوناتها في نفس اللحظة.
4. **🎥 Video Popups & Steps:** نافذة منبثقة (Modal) لكل أكلة تحتوي على فيديو يوتيوب تعليمي، المكونات بدقة، والسعرات الحرارية.
5. **🛒 Interactive Shopping Cart:** سلة مشتريات تتيح إضافة الوجبات، وتعديل الكميات (+/-)، وحساب إجمالي السعر لحظياً، وحفظ بيانات التوصيل في `localStorage`.
6. **📱 Fully Responsive:** تصميم متجاوب 100% يعمل بكفاءة وسرعة على الحواسب والهواتف الذكية.

---

## 💻 Tech Stack (التقنيات المستخدمة)

- **HTML5:** Semantic layout, accessible modal dialogues, and responsive video embedding.
- **CSS3:** Custom animations, gradient shifts, CSS Grid, Flexbox, and mobile breakpoints.
- **JavaScript (ES6+):** Dynamic DOM rendering, array filtering (`filter`, `some`, `map`), cart state management, and LocalStorage integration.
